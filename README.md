# ResolveHub

An independent helpdesk ticket management application for Adwaith KS. Built around shared agent queues, secure ticket claiming, customer messages and internal notes, SLA deadlines, and auditable status transitions.

## Stack
React + Vite frontend, Express/Node API, PostgreSQL, secure agent sessions.

This is a separate implementation of the same support-desk problem as Frontdesk, with an original dark violet interface. See source files for setup and details.

## Getting started
Create a local PostgreSQL database, configure `.env` using `.env.example`, install dependencies with `npm install`, and start development with `npm run dev`.
